# Dany_AI_Studio
Dany AI Studio (v2.7) es una suite audiovisual híbrida para Windows y Google Colab. Incluye la interfaz web completa para componer canciones con ACE-Step 1.5 y YuE 2, generar portadas en alta resolución con Krea-2 Turbo (ComfyUI + Qwen3-VL), masterizar audio a estándar EBU R128 (-11 LUFS), crear vídeos cinemáticos y conectar con GPU
